# MockItDown.js

The MockItDown python library defines UX mockups for use in Markdown pages, typically rendered to HTML through Zensical or MkDocs.  This works well for documentation projects, but being able to create equivalent mockups in a web app for illustration purposes is also needed.  This is primarily to support online design tools where a user can edit the mockups.

This library defines a set of web components for working with MockItDown designs.  It includes both a renderer which takes the design as a CDATA block, and supporting designer tools for web apps that include a mockup designer.
