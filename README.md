# MockItDown Designer (Prototype)

This app is a design tool and reference implementation for creating Mockitdown mockups for use in design specifications.

The MockItDown project includes Python and TypeScript libraries for defining UI mockups for a wide variety of UI frameworks with SwiftUI syntax.  The Python library is primarily used to render mockups in web pages generated from Markdown files.  The TypeScript library provides web components to render the same mockups, with additional web components that can be used to create apps that create and edit the mockups.

This is currently an Electron app, but may be migrated to Positron in the future.

# Development

This is a VibeItOut rapid prototyping project.  Its design and technical specification is documented during development and can be used as a starting point to build a production version of the application with a sound architecture and stable codebase with SpecItOut.
